U613 «Таймер» для Amazfit Bip Max — полное приложение (9 таймеров занятий + красный на 15 минут).

КАК УСТАНОВИТЬ (так же, как вы уже ставили простую версию)
1. В вашем репозитории на GitHub (публичном) удалите старые файлы часового приложения и загрузите ВСЁ из этой папки
   (включая скрытую папку .github) в корень. Либо создайте новый публичный репозиторий.
2. Settings -> Pages -> ветка gh-pages (если ещё не включено). Вкладка Actions: дождаться зелёной галочки.
3. Releases -> QR-код "square-432x514" -> в Zepp: Профиль -> часы -> Режим разработчика -> сканировать.
4. Приложение на телефоне — то же, что уже стоит (5.8), менять не нужно. Zepp и LuvU613: батарея «Без ограничений».

КАК ПОЛЬЗОВАТЬСЯ
- Нажатие на квадрат — запуск, на его месте идут минуты (60…1); ещё нажатие — пауза (жёлтые цифры).
- Час закончился: вибрация, +1 час в трекере, отсчёт заново. Идёт только один таймер.
- Красный: 15:00 с секундами, в конце три сильные вибрации, сам не перезапускается.
- Долгое нажатие на красный — тестовый режим (час = 1 минута, в трекер НЕ засчитывается, только проверка связи); ещё раз — выйти.
